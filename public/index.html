Control Center

What this is

Control Center is the single place to adjust every setting that the app exposes for tools, performance, UI, scene modes, the map toolbar, dashboard preferences, platform toggles, and SIM sensor defaults. Changes are saved to the browser (localStorage key simplex_runtime_overrides_v1) and merged at runtime over public/data/config/app-config.json and tileset Project.Optional_tools.

Use the Filter field in the header to narrow sections by keyword (tool id, “fog”, “layers”, etc.). Workspace covers the tool catalog, feature flags, layer defaults, theme, and top navigation visibility. Scene & map groups analysis buttons, scene modes, and map-strip tools to match smart3dToolbarWireup.

How to use

  1. Open each tab, adjust values, then click Save all. The viewer applies performance, window.t (toolbar visibility), chrome, and local prefs immediately.
  2. Reset runtime overrides removes only Control Center stored data; reload the page to pick defaults from JSON files again.
  3. Reset local prefs also clears Dashboard settings, platform controls, and SIM sensor keys — reload afterward.
  4. Use Backup to export or import a JSON snapshot for the same machine or another profile.

Where things map

  • Performance — jsonConfigManager / renderLoopManager / tilesetViewer.applyDisplayPerformanceSettings.
  • App & tools — tools.items (toolbar catalog), modules.* (runtime init; synced with catalog on save), features.*, ui.*.
  • Appearance — ui.theme (light/dark body theme), ui.sidebars (left/right collapse, optional minimized bottom tool strip), ui.chrome (top bar buttons).
  • Scene & toolbar — Project.Optional_tools → window.t; drives sub-toolbar and tool strip via smart3dToolbarWireup.
  • Local prefs — appSettings, platformControlsSettings, simSensorConfig.

File on disk (app-config.json) is not overwritten from here. For permanent project defaults, edit that file or export from Backup and merge manually.

AppSettingsFramework (js/core/appSettingsFramework.js) registers every storage key, applies linked modules after jsonConfigUpdated, and powers full JSON export/import (version 2).

Open the Project tab for a complete first-party file list (every public/js module except vendor), storage-key registry, and how each area connects to settings.

Backup & restore

Export includes merged app config, current optional-tools patch shape, and local preference blobs.

Danger zone

Resets only affect browser storage, not your repo files.
